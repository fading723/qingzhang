# 青账

让每一笔花费都有迹可循。

青账是一款以本机存储为主的个人记账应用，支持 iOS、Android 和网页预览。记录消费的**年月日及具体时分**，查看**每日、每周、每月、每年**的收支，让账户、预算和账单使用同一套金额与时间规则。

默认简体中文、人民币、单个账本。首次使用是空账本；无需注册，没有广告、第三方行为统计或账本云同步。

## 功能

| 模块 | 功能 |
| --- | --- |
| 首页 | 今日与本月收支、净资产、预算进度、近七日消费、最近流水、待确认周期账单 |
| 记一笔 | 支出、收入、转账、退款；金额键盘、账户、两级分类、备注、标签、复制及连续记账 |
| 消费时间 | 默认当前时间，可精确选择年月日与时分，支持补记；列表和报表按发生时间统计 |
| 账单 | 按天分组、分页、编辑和删除；按时间、类型、分类、账户、金额、标签与备注筛选 |
| 统计 | 日／周／月／年汇总与历史周期切换；收支趋势、分类占比、消费排行及图表下钻 |
| 账户 | 现金、银行卡、微信、支付宝、信用卡及其他账户；期初余额、转账、还款和余额校准 |
| 分类 | 两级分类，自定义名称、图标、颜色和排序；停用后保留历史记录 |
| 预算 | 月总预算、分类预算，展示已用、剩余与超支；80% 和 100% 应用内提示 |
| 周期账单 | 按日、周、月、年生成待办，手动确认或跳过；原生版支持系统本地通知 |
| 数据迁移 | CSV 模板、导入预览、重复检查、流水导出；完整 JSON 备份与恢复、恢复前安全副本 |
| 外观 | 浅色、深色、跟随系统；手机底部导航和宽屏侧边栏 |

## 开始使用

1. 在“我的 → 我的账户”设置自己的账户和期初余额。
2. 点击“记一笔”，填写金额、分类、账户和消费时间。
3. 在“账单”查找或修改记录，在“统计”切换日、周、月、年报表。
4. 按需设置预算与周期账单。周期提醒不会自动认定已付款，确认后才生成流水。
5. 定期在“我的 → 备份与迁移”导出完整 JSON；换设备时使用该文件恢复。

## 本地运行

技术栈：Expo 58、React Native 0.88、React 19、TypeScript；原生版使用 SQLite，网页使用 IndexedDB。

使用 Node.js 24.x（24.3 或更高；已有验证环境为 24.15.0）。克隆本仓库后，在项目根目录执行：

```sh
npm ci
npm start
```

`npm start` 启动 Expo 开发服务。兼容当前 SDK 的 Expo Go 可用于部分功能预览，但不会应用本工程的原生配置插件；系统通知、文件行为及备份排除需要独立安装包验证。

浏览器开发预览：

```sh
npm run web
```

生产资源预览：

```sh
npm run export:web
npm run preview
```

打开终端显示的 `http://127.0.0.1:4173`。该静态预览服务仅监听本机地址，不是手机安装网址。各浏览器和原生 App 的账本彼此独立，不会自动同步。

## 构建安装包

### Android：Windows 本地构建

安装项目依赖后，在 PowerShell 中运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build-android.ps1 -AcceptAndroidLicenses
```

`-AcceptAndroidLicenses` 表示接受 [Android SDK 许可条款](https://developer.android.com/studio/terms)。脚本从官方源下载项目内工具链并校验下载文件，不要求全局安装 Android Studio。首次构建需要网络。

默认生成 `artifacts/qingzhang-1.0.0-android-preview.apk`，可传到支持的 Android 手机上安装。APK 包含离线运行资源，不需要连接开发电脑；当前使用本地测试签名，正式发布需要由发布者保管的签名密钥。工具版本、其他架构和校验方法见 [安卓构建说明](docs/ANDROID_BUILD.md)。

### EAS 云构建与 iOS

云构建需要自己的 Expo 账号，并先关联自己的 EAS 项目。配置见 [`eas.json`](eas.json)：

```sh
npx eas-cli build --platform android --profile preview
npx eas-cli build --platform ios --profile preview
```

- `preview`：内部分发；Android 输出 APK，iOS 使用真机签名配置。
- `simulator`：iOS 模拟器构建，不能安装到 iPhone。
- `production`：正式分发构建配置；Android 输出 AAB。配置本身不代表已发布到应用商店。

此项目的 iOS 真机云构建需要 Apple 开发者签名和设备登记。在 macOS 配置 Xcode 后，可运行 `npm run ios` 进行本地开发；Windows 不执行 Xcode 或 iOS 原生本地编译。分发条件见 [Expo 内部分发说明](https://docs.expo.dev/build/internal-distribution/)。

## 数据与隐私

- 应用业务代码不配置账本服务器、广告、第三方分析或远程推送 token；原生更新下载已禁用。依赖安装、开发服务和可选云构建属于开发流程，不代表 App 会上传账本。
- 原生账本在应用私有目录中保存为 SQLite；网页账本保存在当前站点的 IndexedDB。**当前没有应用层数据库加密、应用锁或生物识别保护。**
- Android 配置禁用系统备份，并排除云备份和设备迁移；iOS 配置插件对账本及恢复前副本目录设置备份排除。Android 规则已做包内静态检查，iOS 系统行为仍需真机验证；Expo Go 不具有这些独立 App 配置。
- 手动导出的 JSON 和 CSV **未加密，包含财务数据**。文件只在用户主动导出时交给系统分享／保存界面，导出后的保管与分享范围由用户决定。
- 本地通知默认使用通用文案。导出的临时副本有过期清理策略，但系统分享返回不等于接收端读取完毕，清理是后续导出时尽力执行，不保证后台定时删除。
- 卸载 App、清除应用／站点数据或浏览器存储被回收可能导致本机账本丢失。排除系统备份意味着换机前需要主动导出完整备份。
- 没有服务器上传不等于“零隐私风险”。检查范围、修复记录与剩余边界见 [隐私检查说明](docs/PRIVACY.md)。

## 记账口径

- **金额**：数据库按整数“分”保存与计算，最多两位小数；校验安全整数边界。
- **时间**：发生时间与创建／更新时间分别保存。列表和报表使用发生时间，固定北京时间，周一开始一周，月／年使用自然周期。
- **净支出**＝支出原额－退款；**结余**＝收入－净支出。退款抵减退款发生期间的支出，预算采用净支出；分类占比采用支出原额并单列退款。
- 转账、信用卡还款、期初余额和余额调整不计入收入或支出。信用卡消费记一次支出，欠款以负余额计入净资产。
- 退款关联原支出，支持部分及多次退款，累计不能超过原金额；已退款的支出受编辑和删除关联校验保护。
- 停用账户、分类保留历史，依赖它们的周期规则会暂停。每期周期账单仅可确认一次；月末日期不存在时取当月最后一天。
- 本地通知最多预排未来 30 期，打开 App 时补排。未授权通知或未收到通知时，首页仍按规则显示待确认账单。

## 导入、备份与恢复

优先在“我的 → 备份与迁移”下载适合当前账本的 CSV 模板；仓库也提供 [示例模板](examples/transactions-template.csv)。导入前需先建立账户与分类，保持表头不变。导入会预览错误行和疑似重复记录，重复 ID 阻止整体导入；暂不直接识别银行、微信或支付宝的原始账单。

CSV 用于交换流水，**完整迁移请使用 JSON 备份**。恢复会先校验版本、金额、结构及关联，再保存当前账本的安全副本，最后原子覆盖。校验或写入失败时不发布新账本。只有确认导出文件已保存后，才更新最近备份时间。

详细存储与迁移设计见 [本机数据说明](src/data/README.md)。

## 验证与测试

```sh
npm run typecheck
npm test
npx expo export --platform all
```

测试覆盖金额精度、北京时间边界、跨月跨年、闰年、退款、转账和还款、预算、周期去重、CSV／JSON 往返，以及真实 SQLite 迁移、事务回滚和修订冲突。

浏览器 UI 和一万条流水性能检查使用独立浏览器上下文及生成的测试数据。先运行上面的生产资源预览，再在另一个 PowerShell 终端执行：

```powershell
$env:QINGZHANG_TEST_URL = 'http://127.0.0.1:4173'
npm run test:ui
npm run test:performance
```

浏览器测试需要本机安装 Microsoft Edge（脚本使用 Playwright 的 `msedge` 通道）。脚本入口见 `scripts/`；测试结果与截图输出到被 Git 排除的 `artifacts/`。已打开页面中的断网操作检查，不等同于网页离线冷启动验收。已执行结果、复现信息和待真机检查项见 [验证记录](docs/VALIDATION.md)。

## 工程结构

```text
src/
  domain/       金额、时间、账户、分类、流水、预算及周期规则
  data/         SQLite / IndexedDB、版本迁移、CSV 与 JSON
  services/     文件选择与导出、安全副本、本地通知
  store/        串行提交与保存成功后的状态发布
  screens/      主页面与管理界面
  ui/           主题与共享组件
plugins/        原生备份排除配置
scripts/        构建、预览、打包及浏览器验证
tests/          领域与持久化测试
examples/       CSV 导入模板
docs/           构建、验证及隐私说明
```

应用名称、图标和包标识配置在 [`app.config.ts`](app.config.ts)。`android/` 和 `ios/` 是 Expo 生成目录，不提交到本仓库；需要长期保留的原生配置应写入配置文件或 config plugin。
