## 一万条流水的实测

以下为桌面 Edge 隔离环境中的端到端 UI 交互耗时，包含渲染等待，不是原生手机性能承诺。

| 操作 | 耗时 |
| --- | ---: |
| 选择完整备份并校验预览 | 527 ms |
| 确认恢复至页面渲染 | 447 ms |
| 打开账单首屏 | 224 ms |
| 加载下一页 | 192 ms |
| 搜索唯一备注 | 128 ms |
| 日／周／月／年报表 | 129 / 76 / 77 / 91 ms |
| 重载读取一万条 | 412 ms |

首屏载入 60 条、实际挂载 14 行；下一页载入累计 120 条。四周期的数量、收入、支出、退款和结余使用独立时间范围计算进行核对。测试脚本与报告保留了浏览器版本、静态快照哈希及时间。该浏览器会话未记录到向站点以外地址发起的 HTTP(S) 请求；这不是原生全生命周期抓包结论。

## 原生验收边界

- Android 发布包适用于 Android 7.0+ ARM64 手机，包含离线运行的 JavaScript/Hermes 资源。Manifest 和两代备份排除 XML 已核对：旧备份、云备份及设备迁移的五类数据均排除。正式发布文件及签名指纹见上方记录，最初的调试签名包历史见 `ANDROID_BUILD.md`。
- 当前没有通过 ADB 连接的安卓设备，未宣称完成安卓真机验收。
- 尚未进行 iPhone 真机验收。Windows 上没有执行 Xcode、CocoaPods 或 iOS 原生编译；Swift 备份排除注入已通过配置 mod 测试，iOS Hermes 资源包已成功生成。
- 发布前应在独立 App 真机完成：飞行模式重启与记账、通知授权／拒绝与到期提醒、系统文件选择／分享、跨设备 JSON 恢复、系统大字体、键盘遮挡和系统备份排除。浏览器使用 IndexedDB，不能代替这些平台检查。
- GitHub Release 使用项目专用签名，密钥由发布者保管。此前的调试签名包需先导出完整备份，卸载后安装新包再恢复；后续同签名版本仍应验证覆盖升级后的数据保留。

## 复现

运行说明见根 `README.md`；安卓工具链详见 `ANDROID_BUILD.md`。浏览器验收脚本：`scripts/ui-smoke.cjs`、`scripts/ui-screenshots.cjs`、`scripts/performance-smoke.cjs`。它们使用独立浏览器上下文和测试账本，不修改用户已有浏览器或正常应用数据。

本轮预览使用 `node scripts/serve-ui.cjs artifacts/privacy-export 4185`，验收时设置 `QINGZHANG_TEST_URL=http://127.0.0.1:4185`。构建和浏览器需要可写的进程临时目录；本机受限运行环境曾阻止 Hermes / Edge 写入临时文件，后在正常权限的独立测试环境完成上述检查。原始日志和测试账本只留在本地 `artifacts/`，不提交 GitHub。隐私检查方法与剩余边界见 [隐私检查说明](PRIVACY.md)。
